# ✨ Beauty AI Assistant

A smart AI-powered salon chatbot built using Python, Streamlit and Groq AI.

## 🌟 About the Project

Beauty AI Assistant is a virtual salon customer support chatbot. It helps customers learn about salon services and submit appointment requests.

## 🚀 Features

- AI-powered customer support
- Haircut service information
- Hair Spa service information
- Facial service information
- Hindi and English conversations
- Appointment request form
- Google Sheets booking integration
- Chat history and Clear Chat option
- Modern dark premium UI

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- Google Sheets API
- gspread
- Google Authentication

## 📅 Appointment Booking

Customers can submit their:
- Name
- Phone Number
- Selected Service
- Appointment Date

Booking requests are saved in Google Sheets.

**Note:** Submitting a request does not automatically confirm an appointment.

## 💻 Project Setup

1. Clone this repository.
2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Configure your API key and Google service account credentials using Streamlit Secrets.
4. Run the application:

```bash
streamlit run app.py
```

## 🔐 Security

Never upload API keys, private keys, passwords or service account credentials to GitHub.
